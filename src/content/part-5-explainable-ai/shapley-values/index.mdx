<Hook>
  **LIME** — short for **Local Interpretable Model-agnostic Explanations** — has a local line with a slope, but splitting a *single* prediction's credit fairly among several features isn't the same problem — especially when two features are worth far more together than either is alone. Shapley values, borrowed whole from 1950s game theory, are the one way to do that split that's provably fair.
</Hook>

<Intuition>
  <IntuitionDemo />

  A pizza's quality score, built from three upgrades: fresh dough, extra cheese, toppings. Cheese and toppings together are worth much more than their solo effects added up — a real synergy. The bars are each feature's Shapley value: the one splitting of the total credit that accounts for that synergy fairly.
</Intuition>

<Formalize>
  Add features to an empty pizza in some order, and each one's *marginal contribution* is how much the score jumps when it joins:

  $$
  \text{marginal}(\pi, i) = v(\{\text{features before } i \text{ in order } \pi\} \cup \{i\}) - v(\{\text{features before } i \text{ in order } \pi\})
  $$

  <Variables>
    <Variable>**$\pi$** — one possible order in which features could arrive.</Variable>
    <Variable>**$i$** — the feature whose contribution is being measured.</Variable>
    <Variable>**$v(S)$** — the value function: the score achieved by a coalition (subset of features) $S$.</Variable>
    <Variable>**$\text{marginal}(\pi, i)$** — how much the score jumps when feature $i$ joins, given the features already present ahead of it in order $\pi$.</Variable>
  </Variables>

  A feature's Shapley value is that marginal contribution, averaged over *every possible order* features could arrive in:

  $$
  \phi_i = \frac{1}{n!}\sum_{\pi} \text{marginal}(\pi, i)
  $$

  <Variables>
    <Variable>**$\phi_i$** — feature $i$'s Shapley value: its marginal contribution, averaged over every possible arrival order.</Variable>
    <Variable>**$n$** — the total number of features being split credit among.</Variable>
  </Variables>

  <Steps>
    <Step label="Averaging over every order is what makes this fair">
      A feature that only pays off *in combination* with another gets credit for that exactly as often as
      the ordering happens to reward it, rather than however an arbitrarily chosen single order would credit it.
    </Step>
  </Steps>
</Formalize>

<Play>
  <PlayDemo />

  Step through all six arrival orders. Extra cheese's marginal contribution swings from as little as $2$ (arriving first, alone) to as much as $13$ (arriving after toppings, where the synergy kicks in) — the *same* feature, wildly different credit, depending only on who got there first. The Shapley value is the one number that averages all six of those swings into a single fair answer.
</Play>

<WorkedExample>
  Baseline (no upgrades) scores $50$; the full pizza scores $80$ — a gap of $30$ to split three ways:

  <Steps>
    <Step label="Order matters for any one feature">
      - In the order dough → cheese → toppings, cheese joins a pizza that already has dough:
        $v(\{A,B\})-v(\{A\}) = 62-55 = 7$.
      - In the order toppings → cheese → dough, cheese joins a pizza that already has toppings:
        $v(\{B,C\})-v(\{C\}) = 65-53 = 12$.

      Same feature, same final pizza, different credit, because cheese's payoff depends on what's already
      there.
    </Step>
    <Step label="Average over all 6 orders">
      Each feature's marginal contribution across all 6 orderings:
      - Fresh dough: $5, 5, 10, 15, 8, 15$ — summing to $58$, so $\phi_A = 58/6 = 29/3 \approx 9.67$
      - Extra cheese: $7, 19, 2, 2, 19, 12$ — summing to $61$, so $\phi_B = 61/6 \approx 10.17$
      - Toppings: by the same process, also summing to $61$, so $\phi_C = 61/6 \approx 10.17$

      Extra cheese and toppings tie, even though their solo effects ($2$ and $3$) weren't, because they
      share the same synergy with each other in every ordering that puts them together.
    </Step>
    <Step label="The credits add up exactly">
      $9.67 + 10.17 + 10.17 = 30$ — precisely the gap between the baseline and the full pizza. This isn't a
      coincidence: it's the *efficiency* property built into Shapley values by construction.
    </Step>
  </Steps>
</WorkedExample>

<ShapleyCheckpoint />

<Summary>
  $$
  \phi_i = \frac{1}{n!}\sum_{\pi} \text{marginal}(\pi, i)
  $$

  Shapley values are the *unique* way to split credit that satisfies a short list of fairness axioms — efficiency (credits sum to the total), symmetry (identical features get identical credit), and a couple of others game theorists proved decades before anyone applied this to machine learning. The catch is cost: with $n$ features there are $n!$ orderings to average over, which is fine for three features and impossible for three hundred. The next chapter is about making this practical for a real, trained model.
</Summary>
